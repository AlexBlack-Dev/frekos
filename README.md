# Frekos

**Bold ideas, shipped with quiet precision.**

An independent design & engineering studio landing page. Full-screen liquid cursor-reveal hero, rem-based adaptive grid, count-up loader, and a request modal built as a single self-contained experience.

## Tech Stack

- Next.js
- TypeScript
- Framer Motion
- Lenis
- CSS Grid

## Features

- Liquid cursor-reveal hero with canvas
- Responsive rem-based adaptive grid
- Animated count-up loader
- Request modal as a self-contained component
- Smooth scroll with Lenis
